# Terminologie — Projektglossar (testautomatisierung)

> Ergänzt das Domänenglossar `docs/shared_rules_knowledge/knowledge/terminologie.md` um Begriffe,
> die nur in diesem Projekt vorkommen. Angelegt 2026-09-11.

## Begriffe
- **Prozess-Plan** — Plan für den Lifecycle einer neuen Version (Eingang → Deployment →
  Durchführung → Umfang → Feedback), ausdrücklich kein Testfall-Katalog. *Quelle:* PROJECT_PLAN 0.
- **Beispiel-Plan / Schablone** — der reduzierte Plan für eine Komponente, zugleich Vorlage für
  weitere. *Quelle:* PROJECT_PLAN 0.
- **Pilotlauf** — erster Durchlauf, der Fach-Ebene (Komponente testen) und Meta-Ebene (Plan
  validieren) gleichzeitig bedient. *Quelle:* PROJECT_PLAN 0.
- **Erfahrungsrückfluss** — Erkenntnisse fließen laufend, vor Abschluss, in die Entwicklung
  zurück; das Erfolgskriterium des Plans. *Quelle:* PROJECT_PLAN 0.
